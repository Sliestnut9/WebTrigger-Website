Build Your Deck
Create the interface you wish existed.

A WebShell is a browser-based control layout for WebTrigger. Create actions once, then arrange them into a simple button deck, system dashboard, home automation panel, or fully themed command center.

Make Every Button Yours
Create actions for apps, websites, commands, PowerShell, Python, hotkeys, and HTTP pull/post requests. Add icons, categories, cooldowns, admin launch, and confirmation prompts.
Local by Design
Set a PIN on first launch. Devices on your network connect to your own PC, so controls stay local without accounts, cloud routing, or subscriptions.
Interfaces You Can Rebuild
Choose a bundled layout, swap to a shared one, or build your own with plain HTML, CSS, and JavaScript.
Live Status, Not Static Keys
Show volume, mute state, CPU, RAM, battery, charging, and custom PowerShell values so your control panel can react to what your PC is doing.
PC Controls on Any Screen
Trigger media keys, volume, lock, sleep, restart, shutdown, Task View, fullscreen, and Task Manager from the device beside you.
Scan and Start Pressing
Quick Connect shows a local URL and QR code so another device can connect in seconds, without hunting for an IP address.
Setup
Install, build, scan, control.
1
Install WebTrigger on your Windows PC
Run the app on the machine you want to control. WebTrigger sits in your system tray and serves your controls locally.
2
Build the buttons you wish existed
Add apps, scripts, hotkeys, websites, folders, system controls, and live values, then choose the WebShell layout that fits the job.
3
Scan Quick Connect from any screen
Open Quick Connect and scan the QR code from a phone, tablet, laptop, or kiosk browser on your network.
4
Use your custom deck instantly
Launch apps, trigger scripts, check live stats, and control system functions from the layout running in your browser.

Import & Export
Package and share your setup

A .wtp file is a WebTrigger Package. Export selected actions, live data sources, and themes/WebShells into one portable file, then back it up, move it to another PC, or share a ready-made setup with someone else.
