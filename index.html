Capabilities
Everything you need to control your PC from anywhere on your network.

WebTrigger combines a Windows desktop manager, a local web server, WebShell themes, live data, launch folders, and system controls into one practical control surface.

Custom Actions
Create actions for applications, websites, commands, PowerShell scripts, and hotkeys. Add categories, icons, cooldowns, admin launch, and confirmation requirements.
PIN-Protected Access
Set a PIN on first launch. Devices on your local network connect through the WebTrigger server — no accounts, no cloud, no outside access.
WebShell Themes
Choose a bundled WebShell, swap to a community theme, or build your own. Each shell is plain HTML/CSS/JS — dropped into a folder and active instantly.
Live Data Sources
Built-in sources track volume, mute state, CPU, RAM, battery, and charging. Custom PowerShell sources let themes display any local value you care about.
System Controls
Media keys, volume, lock, sleep, restart, shutdown, Task View, fullscreen, and Task Manager — all triggerable from any device running your WebShell.
Quick Connect
The Windows app shows a local URL and QR code so you can connect from another device in seconds — no IP hunting, no manual entry.
Setup
Up and running in minutes.
1
Install WebTrigger on your Windows PC
Download and run the installer. WebTrigger sits in your system tray and starts a local server automatically.
2
Set a PIN and add your actions
Secure your server with a PIN, then create actions — apps, scripts, hotkeys, system controls — and choose your WebShell.
3
Scan Quick Connect from any device
Open the Quick Connect window in WebTrigger and scan the QR code from your phone, tablet, or any browser on your network.
4
Control your PC from anywhere on your LAN
Launch apps, trigger scripts, check live stats, and control system functions — all from your WebShell in a browser.

Your Interface. Your Rules.
